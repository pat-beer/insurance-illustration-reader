ตาราง Surrender Value + XIRR
 
เครื่องมือนี้อ่านตารางจากเอกสาร Word โดยอัตโนมัติด้วยการจับคู่คำสำคัญ (Guaranteed / Non-Guaranteed / Surrender Value / Death Benefit / Account Value ฯลฯ) ผลลัพธ์อาจคลาดเคลื่อนหากรูปแบบเอกสารแตกต่างจากมาตรฐานทั่วไป โปรดตรวจทานตัวเลขกับเอกสารต้นฉบับก่อนนำไปใช้กับลูกค้า เอกสารทั้งหมดถูกประมวลผลในเบราว์เซอร์ของคุณเท่านั้น ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ภายนอก
XIRR คำนวณจากกระแสเงินสด: เบี้ยประกันจ่ายเป็นงวดรายปี (อนุมานจากคอลัมน์ Total Premiums Paid) เทียบกับ Surrender Value ที่ได้รับ ณ สิ้นปีกรมธรรม์นั้น ๆ เป็นตัวเลขประมาณการเพื่อการวิเคราะห์เบื้องต้นเท่านั้น

คำอธิบายศัพท์

Guaranteed / Non-Guaranteed มูลค่าเวนคืน

Guaranteed คือมูลค่าเงินสดที่บริษัทประกันสัญญาว่าจะจ่ายให้ หากเวนคืนกรมธรรม์ในปีนั้น — ไม่ขึ้นกับผลลงทุนว่าจะดีหรือไม่

Non-Guaranteed คือส่วนโบนัสหรือผลตอบแทนที่ประมาณการไว้ในเอกสาร แต่ไม่ได้สัญญา จะสูงหรือต่ำกว่าที่เห็นก็ได้

Death Benefit Guaranteed (B) / Cash Value (A) / Non-Guaranteed (C+D) / Net

กรมธรรม์แบบมีส่วนร่วมในกำไรจะเทียบสองก้อน: (B) ทุนประกันที่การันตี กับ (A)+(C+D)=(E) ซึ่งคือมูลค่าเงินสดการันตีบวกโบนัสที่ยังไม่การันตี

Net Death Benefit คือยอดที่สูงกว่าระหว่างสองก้อนนี้ — นั่นคือเงินที่ผู้รับผลประโยชน์น่าจะได้รับในสถานการณ์ที่เอกสารแสดง

Total Surrender Value vs Total Surrender Value (No Withdrawal)

Total Surrender Value คือมูลค่าเวนคืน ณ ปีนั้น หลังหักผลจากการถอนเงินแล้ว

เส้นจาง (No Withdrawal) คือมูลค่าที่กรมธรรม์จะมี หากไม่เคยถอนเงินออกเลย — ใช้เทียบว่าการถอนลดมูลค่าลงเท่าไร

XIRR อัตรามูลค่าเติบโต “ทบต้นตามเวลา”

อัตราผลตอบแทนทบต้นต่อปี ที่ทำให้กระแสเงินสดสมดุล: เบี้ยที่จ่ายออกไป เทียบกับมูลค่าเวนคืนที่ได้รับคืนในปีนั้น (รวมเงินที่ถอนไปแล้วถ้ามี)

ไม่ใช่ดอกเบี้ยที่บริษัทสัญญาจ่าย แต่เป็นตัวเลขประมาณการเพื่อเทียบสินค้าและดูว่าคุ้มทุนเมื่อไร

Cash Breakeven / Guaranteed Breakeven ธงแดง / ธงเขียว

Cash Breakeven (ธงแดง) คือปีที่ XIRR เพิ่งตัดผ่าน 0% — มูลค่าเวนคืนเริ่มคุ้มกับเบี้ยที่จ่ายไปทั้งหมด

Guaranteed Breakeven (ธงเขียว) คือปีที่เฉพาะส่วนการันตีตามทันเบี้ยที่จ่าย โดยไม่พึ่งโบนัส

ปีที่แสดงเป็นทศนิยม 1 ตำแหน่ง เพราะประมาณค่าระหว่างปี เช่น ปี 8.3 หมายถึงราว ๆ กลางปีที่ 8–9

Prepayment จ่ายเบี้ยล่วงหน้า

จ่ายเบี้ยที่เหลือทั้งหมดเป็นก้อนเดียวตอนต้น แทนที่จะจ่ายทีละปี มักได้ส่วนลดจึงทำให้เบี้ยรวมต่ำกว่า แต่เงินออกจากกระเป๋าเร็วกว่า

Notional Amount After Cash Withdrawal

ทุนประกันหรือฐานที่ใช้คำนวณความคุ้มครองกรณีเสียชีวิต หลังมีการถอนเงิน

หากถอนต่อเนื่องจนเกินส่วนโบนัสที่ไม่การันตี ทุนนี้จะค่อย ๆ ลดลง และอาจกระทบเงินเอาประกัน

Acc. Withdrawal มูลค่าเงินถอนสะสม

ยอดเงินสดที่ถอนออกจากกรมธรรม์สะสมถึงปีนั้น รวมทุกรอบที่ถอนมาแล้ว

Payout Ratio (Withdrawal) อัตราการจ่ายจากเงินถอน

เงินถอนสะสม ÷ เบี้ยที่จ่ายไปทั้งหมด บอกว่าถอนคืนมาแล้วกี่เท่าของเบี้ย (ยังไม่นับเงินที่ยังอยู่ในกรมธรรม์)

Net / Total Payout Ratio อัตราการจ่ายสุทธิ / รวมเงินถอน

(เงินถอนสะสม + มูลค่าเวนคืนปัจจุบัน) ÷ เบี้ยที่จ่ายไปทั้งหมด

เรียก Net เมื่อยังไม่มีการถอน และ Total (Withdrawal) เมื่อเริ่มถอนแล้ว — สองแบบใช้สูตรเดียวกัน

Total Premium Paid vs Total Premium Paid (Prepayment)

เส้นอ้างอิงสีเทาคือเบี้ยสะสมถ้าจ่ายรายปีตามตาราง ส่วนเส้นประคือเบี้ยสะสมถ้าจ่ายก้อนเดียวล่วงหน้า ซึ่งมักต่ำกว่าเพราะมีส่วนลด

Guaranteed Basis / Current Assumed Basis กรมธรรม์แบบ UL สองฐาน

Guaranteed คือภาพกรณีแย่ที่สุดตามค่าธรรมเนียมและอัตราขั้นต่ำที่บริษัทการันตี — ไม่ใช่ผลที่คาดว่าจะได้

Current Assumed คือภาพประมาณการด้วยอัตราเครดิตคงที่ที่บริษัทเลือกมาแสดงในเอกสาร (อ่านจากเอกสารแต่ละฉบับ) ซึ่งอาจต่างจากผลจริงของกลไก UL/IUL ที่ขึ้นกับผลดัชนีและพื้นอัตรา

เส้น Guaranteed ของ Surrender Value / Death Benefit ไม่ได้มาจากการเอา Account Value (ที่ credit ด้วยอัตราขั้นต่ำ) มาหักค่าใช้จ่าย แต่เป็นตัวการันตีแยกต่างหากที่บริษัทสัญญาไว้ตรง ๆ (เช่น สะสมไม่น้อยกว่า X% ต่อปีในช่วง Y ปีแรก และ Z% หลังจากนั้น) ใช้กับ Surrender Value และ Death Benefit โดยตรง — คนละกลไกกับ Crediting Rate ที่ใช้กับ Account Value เท่านั้น
